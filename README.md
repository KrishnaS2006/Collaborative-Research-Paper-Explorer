# Collaborative Research Paper Explorer

A web application to help researchers discover, manage and collaborate on academic papers. The project includes a React + Vite frontend, a Node.js/Express backend, and a PostgreSQL schema. It provides user authentication flows, rate limiting middleware, and an API for managing user sessions and paper-related data.

## Key features
- User authentication (register, login, password reset)
- Rate-limited API endpoints and middleware
- Web UI with pages for Register, Login, Forgot/Reset password, and Dashboard
- PostgreSQL database schema and migrations (SQL file included)
- Unit tests for backend middleware and routes

## Stack
- Language(s): JavaScript (frontend + backend), PLpgSQL (database schema)
- Framework / runtime: Vite + React (frontend), Node.js + Express (backend)
- Notable libraries: Express (server routing), node-postgres / pg (DB access), Vite + React (frontend), Jest (backend tests)
